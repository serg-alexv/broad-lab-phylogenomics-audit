# Broad-LAB phylogenomics and antiphage defence audit

This private repository is being staged from the authoritative WD Tree 2 workspace. The full archive index and transfer verification will be added before the audit release is published.

The source checkpoint has 1,170 acquired assemblies, 919 source-supported and annotated candidates, a computationally validated 900-tip full-panel tree, and 165 accepted paired defence searches. Another 20 genomes completed both predictors in C009 and await independent file QA. Defence rings and a separate representative tree remain pending.

The snapshot preserves the original methods, intermediate results, validation, failures, and raw defence evidence. Whole-genome and coding DNA, credentials, and machine-local runtime caches are outside the transfer scope.
