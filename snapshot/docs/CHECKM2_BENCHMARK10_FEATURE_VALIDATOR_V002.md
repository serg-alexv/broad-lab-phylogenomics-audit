# Held exact-ten feature validator interface

`checkm2_benchmark10_feature_validator_v002.py --request PATH --request-sha256 SHA --output PATH` is a model-free saved-output validation target. It invokes no annotation, DIAMOND or prediction function. Module loading uses only standard libraries and the unchanged accepted validator's standard-library helpers; NumPy/pandas imports occur inside the admitted runtime only after preflight. Preparation and the five pure fixtures open no actual genome, FAA, pickle or model.

The request uses `request_schema: TREE2_BENCHMARK10_FEATURE_REQUEST_V002` and bound `recipe`, `schema`, `source_manifest`, `protocol_admission`, `runtime_prefix` and `input_plan_sha256` fields. Shared artifacts are `raw_pickle`, `quality_report` and `quality_unit_execution`. Exactly ten member rows provide `accession`, `selected_faa`, `annotation_receipt`, `annotation_unit_execution` and optional `annotation_commit`. File bindings contain path, SHA256 and bytes. Source manifests contain a nonempty `sources` list and must include this validator and its unchanged accepted-validator, original-helper and independent-math dependencies.

The protocol literals are `TREE2_BENCHMARK10_PROTEIN_ADMISSION_V002`, `ADMITTED_ONE_BENCHMARK10_BATCH` and `BENCHMARK10_PROTEIN_METHOD_QC_ONLY`. The protocol must bind the input plan, manifest, exact recipe/limits and accepted closed format-control evidence, permit one batch and carry all reviewed prerequisite gates. This target rejects `BOUNDARY_AFTER_FIRST_ANNOTATION`; it accepts only `CONTINUE` or separately admitted `VALIDATE_COMMITTED_BATCH`. The controller/common layer owns external resume/commit authority, fresh leases, cumulative execution claims and the remaining shared 3,600-second budget. This validator is not a dispatcher or resume authority.

Every annotation unit and the stock batch quality unit must have `UNIT_EXIT0_GROUP_CLOSED`, exact integer exit code 0, an empty owned group and an empty remaining-process list before scientific imports or unpickle. All request/source/protocol/artifact/original-source/JSON hashes are checked first. The actual pinned Python 3.12.16, NumPy 2.5.4 and pandas 3.1.0 origins must lie in the accepted private read-only prefix; model modules remain forbidden. The fresh owned raw dump is loaded once.

Require ten unique exact accession Names and the complete ordered 21,242 columns. A strict five-column stock report is joined by Name, never by row position. Each row is checked against its own selected FAA, source FNA hash, original caller/binary identity, all ten returned values and separate DNA metrics. Validate all 21,241 finite/domain-correct inputs, 22 exact AA metadata values and 1,220 independent pathway/module/category recomputations. Modules retain raw copy counts, duplicates and prefilter denominators; pathway/category calculations use clipped presence. No saved value is clipped, filled or silently corrected. All rows remain measured benchmark diagnostics; none becomes a panel, source or taxonomy pass. Missing, duplicate, extra, unknown or nonfinite rows fail validation rather than becoming zero estimates.
