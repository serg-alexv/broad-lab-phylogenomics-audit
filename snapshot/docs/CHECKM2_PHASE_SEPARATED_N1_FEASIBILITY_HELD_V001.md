## Freshness and immutable queue

Before a later selector can run, Root must approve scope and bind immutable source/candidate/acquisition/824-screen snapshots, the existing 95/priority 92 scope, the Root result registry and an exhaustive historical work index. Build that index by known schema, not an unrestricted string scan: include every annotation/prediction/control request, once-claim, started unit, completed row and explicit control donor mapping across preserved namespaces.

N1 excludes every prior annotation or prediction claim/invocation, including failed, unknown, unaccepted and early-failed attempts. A process need not have reached model loading to consume freshness. Controls and rewrapped inputs map to their original versioned accession and donor DNA identity; a renamed copy is not new. Known repeated DNA/checksum aliases are excluded. Missing donor mappings or unknown history schemas block a freshness assertion. Accepted rows, pending reuse decisions and historical claims remain original; none is recomputed to match new operational source.

The later candidate must belong to the source-supported acquired95 lane and an eligible source label among the 92 missing from 824. QC_PENDING because source contamination is missing or ANI is Inconclusive is allowed for measurement, with those masks retained. The separate 223 held source/review records and 28 MAG/SAG source exclusions are not silently promoted. No source score acts as truth or a missing-as-negative filter.

The proposed deterministic queue ranks the least represented family, then genus in the frozen Root-accepted measurement context, followed by normalized family/genus, integer source species_taxid, recorded assembly-level preference and exact versioned accession. Label context does not authenticate taxonomy. Prefer one accession per missing label before extra strains; keep Daquilactobacillus/Hutsoniella under the same gates. Do not fall through to ordinary strain work if the missing-label lane is unresolved. No queue or accession has been computed here.

The eventual input plan must pin one acquisition-bound genomic FNA, versioned accession, source/candidate rows, pending/type/taxonomy masks, the historical exclusion proof and all queue keys. Its actual FNA/FAA/CDS/contig dimensions become the scope of the control. A fragmented or larger input is new evidence, not an automatically qualified extension of the mostly 1–3-contig method examples.
