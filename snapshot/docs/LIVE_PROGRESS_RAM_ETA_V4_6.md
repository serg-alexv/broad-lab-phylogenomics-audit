# RAM-backed CheckM1 display and timing

The existing display first followed native24152 through a data-only rebind to
the bound V2 launch contract and plan, without restarting. Its frame confirmed
the18 reused measurements and actual raw-search progress in the next32-genome
batch. V4.6 then adds the memory labels and conditional timing calculation;
only the display process is replaced, after two new visible frames.

Memory separates the worker's reported Linux process RSS, private RAM-scratch
usage, and their reported combined total/budget. Missing fields remain
unavailable rather than becoming zero. These are worker reports, not new WSL
probes. The display neither allocates RAM scratch nor changes its lifecycle.

No numerical ETA is produced from the reused cold pilot18 or partial raw HMM
searches. Calibration requires a new batch's `COMMITTED.json` with the current
RAM plan SHA, exact accession rows/claim, and hash/size-bound analyze and QA
receipts proving actual0, reaped children and closed groups. Failed, changed,
partial and different-plan evidence cannot supply a timing sample.

The estimate uses genome-average wall time from the start of each completed
batch claim through its durable measured commit. Genome size and workload vary;
one or a few batches give a sample-limited forecast. Unfinished batches count
in full, so raw partial-search progress does not become fractional QC completion.
The local finish clock is shown only with a fresh matching live running owner.
This estimates remaining method measurements; source/taxonomy/panel review and
outer closure are additional. No rate, confidence interval, or guaranteed
finish time is invented before a complete new RAM batch.

The existing GUI refresh performs these metadata reads every30 seconds. It
adds no daemon or AI polling and reads no protein sequence, domain output or
marker database. Original display and scientific source bytes are preserved.
Synthetic fixtures cover distinct memory components, cold-pilot exclusion,
complete bound-unit calibration, suspended finish clocks and changed QA
evidence. Receipts are under `metadata/monitor_checkm1_RAM_display_v001` and
`metadata/monitor_checkm1_v2_rebind_v001`.
