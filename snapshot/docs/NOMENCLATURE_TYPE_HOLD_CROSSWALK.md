# Nomenclature and type-assertion holds for the reviewed panel entries

This version freezes source-review findings for six ANI components and eighteen genomes. It permits genome QC to proceed, but grants no biological identity, taxonomy, deduplication or final-panel acceptance. Current labels and panel membership remain unchanged. An independently checked culture definition does not authenticate the corresponding sequenced material.

The downstream machine authority is `metadata/nomenclature_type_holds/v001/commit.json`, which binds the crosswalk JSON and two TSV tables. It references the unchanged accepted first-three and next-three source manifests. Cohort QC and eventual panel curation should record this version's manifest SHA; final freeze requires explicit resolution or a documented treatment of every remaining hold. This crosswalk does not itself modify any running analysis or selection rule.

Across all eighteen entries, thirteen source-declared strain/collection identifiers match independently defined type cultures; three of those thirteen retain an unverified personal-alias link. One further identifier matches a proposed reference for an unvalidated name. Four have no independent type anchor established. Zero genomes were physically authenticated by these reviews. Two external sequence-accession string bridges were checked; neither is biological authentication.

The per-genome TSV retains the original `TYPE_MATERIAL` flag and its unverified-scope class separately from these source findings. Unknown type anchoring, missing QC and unresolved biological relations remain explicit.
