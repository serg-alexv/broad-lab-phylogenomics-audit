# N1 pure artifact handshake helpers

The new helper imports only Python standard-library modules. It does not call CheckM2, DIAMOND, models or an interpreter. The implementation is source-only pending the frozen N1 scientific handoff and independent review; it changes no original author code or feature math.

`validate_diamond(tsv_path, accession, allowed_primary_ids)` returns a standard raw artifact row (`path`, `sha256`, `bytes`) extended with row/unique/duplicate counts, a multiset SHA256 covering all 12 fields and exact `query_genomes:[accession]`. Queries must use the original own `accessionΩprimaryID` ABI and an exact allowed FAA primary ID. Targets retain their full nonempty `reference~annotation` string. Targets outside stock default KOs remain present. All 12 raw field strings and duplicate multiplicities remain in the digest; only row order and LF/CRLF convention are normalized. No normalized TSV is emitted and no input bytes are changed.

Numeric checks cover finite nonnegative score/evalue, pident in 0..100, positive integer length and protein coordinates, nonnegative mismatch/gap counts no larger than alignment length, and ascending protein coordinate pairs. A nonempty complete table is required by the stock resume path. A missing, malformed, foreign or empty output raises a technical validation failure; no biological negative or eligibility decision is produced.

`exact_faa_inventory(folder, accession, expected_sha)` admits only the versioned `ACCESSION.VERSION.faa`. `exact_diamond_inventory(folder, expected_file)` admits only `DIAMOND_RESULTS.tsv` matching its pinned path, byte count and SHA256. Both return minimal project-relative artifact rows and reject extras, subdirectories, symlinks/reparse points and nonregular files. File identity/size/mtime and full raw hashes are checked across reading.

Synthetic fixtures exposed an incompatible Windows `lstat`/`fstat` ctime observation for unchanged inode/size/mtime and bytes. The identity comparison therefore uses device/inode/size/mtime, with regular-file and complete raw SHA checks. After this correction, six fixture groups and 20 bounded synthetic stability repeats passed, including actual symlink rejection, sensitivity to all 12 columns, duplicates, outside-KO annotations, invalid IDs/numerics/columns and strict inventories. Only tiny fresh files inside project work were used and removed through the verified owned fixture path. No real FAA/TSV, model, genome or scientific module was opened or executed.
