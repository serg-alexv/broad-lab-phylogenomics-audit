# Future shared-query index8 cohort: source-only, HELD

This provider prepares one primary path for a future cohort of1–20 fresh inputs and1–2 disjoint accepted serial-index8 search-only controls. It changes no active V2 source, Ready, queue, worker or scientific output. It cannot run until a Root-accepted closed serial-index8 method profile with actual native0/WSL0 exists, its exact control FAA/annotation/search/raw references and prior debts are bound, the new provider/OPS receive independent review, and Root separately admits a real cohort.

The core checkpoints all real original annotations first. It uses the unchanged author SeqReader and versioned `accession + Ω + primary_id` transform, explicitly rejecting collisions before combining at most22 inputs. One direct pinned DIAMOND index8/block0.5/thread1 command replaces its producer process. A durable typed binary0/group receipt precedes a separate bounded raw/query validator and lossless splitter. Full12-field strings, duplicate rows, numeric spellings and target identifiers remain intact. No KO filtering or deduplication is added.

Each fresh row then receives its exact own FAA and shard in the existing stock `--genes --resume` layout. The first own model/full21241-feature validation is checkpointed BEFORE the control comparison finishes. Each supplied control annotation and serial search is joined to the actual accepted registry row commit. Full raw multisets of each accepted serial-index8 control must match its shared-search shard, and the real search/raw validation/control/first-own unit receipts must pass, before any remaining model calls start. Accepted controls never repeat annotation or model inference. This is scoped evidence for those exact controls; no universal equivalence, memory fit or speed claim has been established.

One global binary, one raw-validation/split and one control-comparison debit are charged once, with per-row annotation/model/features charged independently. Shards reference the global actual execution and never pretend to have separate standalone search exits. All old actual failed/shared costs remain bound. An empty own shard explicitly holds method QC after a successful no-reported-hits search; it does not create a quality score or biological/defence negative.
