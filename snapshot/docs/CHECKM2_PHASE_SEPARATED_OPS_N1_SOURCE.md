This component is source-only. Root owns independent lifecycle review and any later execution grant. The scientific coordinator owns the common/inner implementation, the one authorized local selection, phase contracts and final combined source cut. Its history/queue review must complete before these provisional OPS files become an executable accepted tuple. The original 75 sources and accepted measurements remain preserved.

The new native, entry and LF shell use only the N1 evidence/analysis/state/request/once-claim paths. They reuse the accepted private namespace, read-only runtime image, read-only effective overlay, IPC alias, unchanged 874 creation/pidfd cleanup, cached 561 optional telemetry and a11 display-only OSError boundary. No model, database, author code, global host setting or earlier result is changed. Native Windows and entry/helper identities remain strict; a later cleanup-only identity cannot establish scientific success.

The cold wall envelope is 3,000 seconds: at most 600 before image-helper dispatch, at most 1,760 for that helper, at most 600 for post-unmount image verification and 40 for fatal cleanup. The image/IPC startup overhead consumes the actual helper window. Entry passes a derived `--helper-deadline-unix`, bounded by both 1,760 seconds and the remaining cold wall minus 640 seconds reserved for closure. The scientific coordinator independently caps each phase by that actual remaining window, its phase allocation and the unspent 1,410-second science allowance. The four proposed science caps are 180/600/600/30; no phase exceeds 600. These are new held N1 allowances; no earlier budget is reset or borrowed.

The native attempts generic stage04 registration before WSL with its actual Windows birth, command and owner token. It starts at zero of one fresh measurement. Cached optional display and publication failures remain separate from required launch/Ready/resource/identity/command/terminal evidence. A completed singleton is counted only from a current token/plan/protocol/namespace pointer, verified manifest and typed `N1_CORE_PENDING_NAMESPACE_NATIVE_CLOSURE` result with exact integer `completed_qc_rows:1` and one row. An inherited ten-row compound result or Boolean count is rejected. Native success remains `N1_OUTPUTS_CLOSED_PENDING_OBSERVED_OWNER_EXIT_REVIEW`; whole-QC, source/taxonomy and production acceptance remain separate.

Partial Windows lock setup closes already-opened descriptors. Fatal entry cleanup retains its actual image-helper handle and the unchanged finite creation-checked cleanup policy; native cleanup requests N1-scoped STOP and waits for its retained WSL handle without treating WSL exit as guest closure. Missing required unit/runtime/IPC/image evidence or unresolved ownership creates a persistent handoff and prevents replay. Full pre/post image hashes and ordinary read-only image/IPC closure remain part of actual future execution, not a claim from this source preparation.
