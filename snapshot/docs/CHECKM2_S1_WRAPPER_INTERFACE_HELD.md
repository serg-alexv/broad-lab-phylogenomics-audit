# S1 wrapper interface: held source only

The new entry/native/LF-shell copies route only to `checkm2_single_faa_common_S1` and `checkm2_single_faa_inner_S1`, with separate S1 evidence, output, progress, launch, request, Ready, STOP and unresolved-ownership paths. They reuse the unchanged874abacc creation-matched pidfd cleanup guard and561164f6 optional telemetry reader. The old48T1source pins remain byte-identical. No input staging, runtime, process diagnostic, inference, Ready or live-stage action was performed to prepare these sources.

Fresh series progress starts at0/10 per-genome QC commits, irrespective of the ten existing annotation commits. RECOVER_CLOSED_ROWS reads only the required authority's accepted_row_commit_sha256s map. Missing/malformed optional counters, identity or detail fields retain the last valid matching-owner snapshot and show an explicit stale/unavailable label. Strict required input, protocol, terminal, manifest and closure reads remain strict. The generic stage04 row is registered with the actual native owner and refreshed every two seconds when a future admitted controller runs; no whole-panel completion is claimed.

Cold wall bounds are proposed for Root review:600seconds before-helper preflight,4760maximum helper duration,600seconds final image verification and40seconds reserved fatal cleanup, totaling6000. Native supervision starts before project imports and expires at5960seconds before bounded40second cleanup. Its immutable request transports the finite remaining Unix deadline; the entry converts that remainder to a local monotonic deadline capped at6000, rejects expired/out-of-contract requests, caps its helper by the remaining posthash/cleanup reserves, and caps final image hashing at600seconds and the global cleanup reserve. These source bounds were not exercised as a process test.

Required common interfaces are plan_gate(path,sha,closed_finalization=False), resume_proof(admission,session), current_failed_run(step,token,plan_sha,protocol_sha), group_receipts_closed(run), and the agreed S1 path constants. Optional progress supplies only a locator for failed runs; common must validate the matching required binding/failure/invocations before group closure can be inferred. Successful runs require the exact current pending pointer and manifest. closed_finalization=True is used only after actual WSL0, verified ordinary runtime/image and current invocation-group success; initial/entry/inner gates stay strict.

The reused874guard still contains historical T1 descriptive strings internally. Its actual STOP write target is the explicitly supplied S1 STOP path, and ownership signals are individual creation-matched pidfds. No T1 STOP path is passed by these wrappers. Forced or unproved cleanup retains UNKNOWN and an immutable per-token handoff plus no-relaunch marker. No WSL-client termination is used as guest cleanup evidence.

The native normal output is S1_OUTPUTS_CLOSED_PENDING_OBSERVED_OWNER_EXIT_REVIEW; the entry's core status is S1_CORE_PENDING_NAMESPACE_NATIVE_CLOSURE. A successful stock single-FAA unit and its feature receipt remain pending actual native/ordinary runtime/lease closure and Root acceptance. No annotation method or fake successful ten-genome bulk receipt is introduced. Root independently reviews these authored OPS wrappers; the author's source parsing is not an independent lifecycle approval.
